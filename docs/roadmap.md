# ChatMaker Beta 路线图

当前 Beta 版本：**0.2.0-beta.2**。状态基准：2026-08-26。

维护者已邀请 20 多位体验者参与测试。Beta 的大白话意思是：核心体验已经能用，也欢迎真实用户使用，但我们仍会根据反馈调整；它不代表所有板卡和模块都完成了实体验收。

## P0：完成精简和事实归一化

状态：已完成。

- ChatMaker 是唯一用户入口，ChatDuino、ChatWeb、ChatCAD 是内部模块。
- 基础 Skill 不再依赖 MCP 或扫描 Codex/WorkBuddy 双宿主。
- 板卡、功能、案例和证据门分别记录，README 与 Knowledge 摘要从结构化事实生成。

## P1：星核板独立 CLI

状态：已完成 Windows x64 最小闭环。

- 不要求安装或启动 Mind+ 桌面应用；已有 Mind+ 1.8 和 2 仍可作为兼容后端。
- 已用“桌面地震预警站”验证环境准备、编译、COM4 上传、硬复位和 115200 串口。
- 中文 OLED、防闪、蜂鸣器和按键的实体效果沿用此前用户确认；后续运行不能用串口提示冒充新的肉眼或耳听验证。

## P2：优先扩展掌控板与 micro:bit

状态：进行中。

### P2.1：经典掌控板 V2.x

- 仓库已有板卡记录和 Knowledge，不从零重写资料。
- 重点补齐独立工具链、代表案例和编译／上传／串口／实体效果分门验证。
- 掌控板 3.0 是不同芯片和屏幕的另一块板，不能混用 V2.x 结论。

### P2.2：micro:bit V2

- 先按[新板卡调研流程](contributing/board-research-workflow.md)核对精确版本和官方资料。
- 比较 MakeCode、MicroPython/CODAL 等正式工具链，再决定 ChatMaker 的独立 CLI 路线。
- V2 优先；V1 只有在真实课堂需求出现时再补兼容。

### P2.3：其他板卡

- 根据 Beta 反馈决定是否把 Nano、Uno 等也迁移到 ChatMaker 管理的独立工具链。
- 每块板继续分别验证编译、上传、串口、断电重启和实体功能。

## P3：Beta 分发、版本与反馈闭环

状态：待 P2 两块优先板卡完成最小闭环后开始。

- GitHub `main` 继续作为当前推荐安装来源。
- 打通 SkillHub 自动部署和更新，让 WorkBuddy 用户能直接安装最新版。
- 每次面向用户的阶段更新同步版本号、README 和 `WHATS_NEW.md`。
- 根据体验者的高频问题修正安装、串口诊断和小白提示。

## P4：稳定版收口

状态：待前面阶段完成。

- 固定支持矩阵、升级策略和对外版本号。
- 完成代表性课堂项目、安装更新、回滚与发布验收。
- 只有真实通过的证据门才能写入稳定版说明。

每完成一个 Phase，先根据体验者反馈更新本页的状态、下一阶段目标和验收证据，再开始下一阶段。P1、P2、P3、P4 是工作阶段，不是下载版本号。
