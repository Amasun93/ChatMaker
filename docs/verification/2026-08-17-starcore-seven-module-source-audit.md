# 星核板七模块来源审计

审计日期：2026-08-17

## 结论

本轮只批准将经过复核的事实改写为 ChatMaker Knowledge、接线指导、库/API 指导、派生示例与去敏机械事实。七个硬件 ID 为：

- IDMD-0001
- IDMD-0002
- IDMD-0021
- IDMS-0001
- IDMS-0003
- IDMS-0008
- IDMS-0009

每个模块使用的来源 ID、内容哈希与批准用途记录在受治理的星核板来源清单中。仓库不记录开发电脑路径，也不复制原始资料内容。

## MP3 板卡合同

批准来源同时确认了以下事实：

- P15 是课堂标准接法中的主控 UART RX，接模块 TXD。
- P16 是课堂标准接法中的主控 UART TX，接模块 RXD；该引脚与启动状态相关，外设不得在上电时强拉。
- 信号板提供独立的 5V/GND 接口组。因此 5V 在 canonical board 中只能表示为供电 rail / connector bank，不能表示为 GPIO。

据此，IDMD-0002 的 P15/P16 与 5V 前置证据已满足；这只解除资料迁移阻塞，不等同于本轮已经完成新示例编译、烧录或实物播放验证。

## 公开与私有边界

可以公开：规范化事实、原创改写的用法说明、来源 ID 与内容哈希、派生示例、去敏机械事实。

保持私有：原始资料字节、开发电脑路径、制造源文件、完整设计工程与生产归档。物理装配效果仍为未验证。
