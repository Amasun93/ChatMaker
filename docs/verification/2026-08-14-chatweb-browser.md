# ChatWeb 浏览器验证

## 验证对象

- 课堂工具：`examples/chatweb/classroom-pulse.html`
- 模拟硬件界面：`examples/chatweb/hardware-console.html`
- 预览运行层：`runtime/chatmaker/web/preview.py`
- 验证日期：2026-08-14

## 本地预览边界

- 默认地址为 `127.0.0.1`。
- 自动测试证明只提供当前选中的 HTML；其他项目文件返回 404。
- 浏览器自动请求的 `favicon.ico` 返回 204，不制造控制台错误。
- 非本机地址必须显式传入 `allow_network=True`。
