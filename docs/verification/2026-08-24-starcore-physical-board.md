# 星核板 v4.2.2 实板验证（2026-08-24）

本记录只陈述本次连接到 Windows 电脑的一块用户确认星核板 v4.2.2 所产生的证据。它不替代其他批次、外接模块、CAN 总线或机械装配测试。

## 环境与身份边界

- 唯一合格有线端口：`COM4`；其余发现端口均为蓝牙端口。
- 芯片读取：经典 ESP32；Flash：16 MiB；Mind+ 1.8 mPython 兼容目标可编译和上传。
- 安全熔丝读取未发现 Flash 加密或安全启动。
- ESP32、CH9102F 和 QMI8658 仍不能单独证明是星核板；精确身份来自用户确认与板上 `星核板 / V4.2.2` 丝印。电子探针正确保持为 `ambiguous`，没有误判成经典掌控板。

## 备份、探针和恢复

- 首次以 115200 读取完整 16 MiB Flash，随后刷入临时探针并恢复；恢复经 `verify_flash` 验证。
- 优化后以 460800 读取完整 Flash，备份 SHA-256 与首次完全一致：`27c6ecd97ffaa28d01b787da5ef0bc65b54b6d756e114ce75795853cc9b851be`。
- 优化后的完整识别事务约 11 分钟；此前约 28 分钟。写回和恢复验证仍使用 115200。
- 备份文件只保存在测试电脑用户目录，未提交到仓库。

## 板载自检

`examples/chatduino/starcore/onboard-self-test/onboard-self-test.ino` 使用当前 Mind+ 1.8 目标编译并上传成功，随后从 115200 串口取得：

- `STARCORE_SELF_TEST_READY`
- `BUZZER_COMMAND_COMPLETE`
- 8 组 A/B 按键空闲状态，均为未按下；
- 8 组 QMI8658 数据，合加速度为 1047–1050 mg，符合静止板卡约 1 g 的预期。

测试结束后原 Flash 再次恢复并通过逐字节验证。

## 仍未验证

- 没有人工按下 A/B 键，因此只验证了空闲读取，未验证按下事件。
- 程序执行了 120 ms 的 880 Hz 蜂鸣命令，但没有人在验收现场确认听感，因此“实际可听见”仍为 `unverified`。
- 没有第二个 CAN 节点，CAN 收发、终端电阻、波特率和协议均未验证。
- 没有外接模块，因此七个自研模块的实物效果仍未验证。
- 没有执行 USB 断电重启验收。
