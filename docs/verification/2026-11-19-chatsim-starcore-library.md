# ChatSim 1.0.0 星核板元件库复测

板型为 IDMC-0001 星核板 v4.2.2。元件库和两项实验可以在已有浏览器里直接打开。体验阶段使用随包的程序。

## 直接体验

```powershell
chatmaker-sim --version
chatmaker-sim --library starcore --open
```

| 卡片标识 | 数量 | 可以做什么 |
| --- | ---: | --- |
| 可互动 | 4 | 在两项实验中操作三线按钮、电位器，观察 OLED 和 RGB 灯 |
| 外观参考 | 7 | 辨认拨动开关、旋钮编码器、光敏、温湿度、超声波、MP3 和三轴加速度模块 |
| 外形与孔位 | 11 | 对照板框、安装孔与已登记的引脚名称 |

每张卡片的编号沿用 ChatMaker 元件卡。卡片引脚标签来自元件资料，接头实际线序按丝印核对。外形图用于课堂辨认，安装孔直径和外壳开孔在制作前仍需量实物。

## WorkBuddy 复测提示词

> 用最新的 ChatMaker 打开 ChatSim 的星核板元件库。先运行 `chatmaker-sim --version`，确认 `chatsim_version` 是 `1.0.0`，并逐字比对 `runtime.source_commit` 与我给你的这次 GitHub 提交。告诉我你实际加载的源码目录和提交号，确认 Skill 与工具来自同一个目录。如果版本没对上，先停在版本检查。然后直接运行 `chatmaker-sim --library starcore --open`，查看全部 22 个元件。打开 OLED 示例，试按 A 键，再松开。返回元件库，打开调色灯，试按外接按钮并转动旋钮，观察灯的变化。最后从接线区域查出按钮、旋钮和 RGB 三个模块的信号分别接到哪里。用几句话告诉我你亲自复测到了什么。

老师可以把本次发布答复里的 GitHub 提交号与这段提示词一同发给测试者。命令行也可用 `--expect-revision <完整提交号>` 做比对，提交不一致时工具会停止生成预览。

## 核对清单

1. 元件库显示 22 项。筛选「可互动」「外观参考」「外形与孔位」分别得到 4、7、11 项。
2. OLED 实验里按住板载 A 键显示「你好」，松开显示「再见」。四根线接同一个 3V3 I²C 插口，时钟是 P19，数据是 P20。
3. 调色实验启动时灯灭。按图上的按钮，亮起来。点「保持按下」，把旋钮移到另一端，灯从红色经过绿色调到蓝色。点「松开按钮」后熄灭。
4. 依次选择「按钮」「旋钮」「灯」，图上显示对应接线。按钮 SIG 接 P8，旋钮 SIG 接 P0，灯的 RED、GREEN、BLUE 分别接 P9、P15、P23。信号线用 S 排，供电用 3V3 与 GND。

## 运行范围与素材维护

- 两项星核实验使用与真板示例共用的程序逻辑。网页提供已接好的虚拟输入和输出。任意星核程序和手动接线由后续版本接入。
- 已用 Windows 上的 Chromium 离线跑过实际生成的元件库，检查桌面预览与 390 像素宽页面。两个示例均从元件库打开，调色灯的按下、松开和旋钮输入已复测。调色灯真板程序用 ChatMaker 的星核独立工具链编译通过。真板上的灯效待实物复测。
- 星核板与 OLED 沿用按课堂资料绘制的正面图。其余辨识图参考课堂模块图、教材和星核电子模组展示。板框尺寸和孔中心取自 [机械卡](../../knowledge/mechanical/components)，引脚名称取自 [电气元件卡](../../packs/components)。新增元件时先核对两类卡片，再用 `python scripts/generate_chatsim_starcore_library.py` 生成浏览器元件清单。有可重复验证的交互示例后再标为「可互动」。
