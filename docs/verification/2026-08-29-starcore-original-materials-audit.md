## 已补进 ChatMaker 的缺口

1. canonical Starcore 板卡新增“8 个物理 I2C 插口、同一共享总线”的结构化事实；3V3/5V 仍按插口丝印选择，不把位置当电压依据。
2. 新手接线规则改为“四芯线整条插入一个匹配电压的 I2C 插口”；SCL/C 与 SDA/D 是相邻信号对，禁止拆线跨接。
3. IDMS-0009 超声波明确为 GPIO 2+2 四芯线：红 VCC、黑 GND、蓝 TRIG→H/P26、绿 ECHO→O/P27；不再把 H/O 与 I2C 的 SCL/SDA 混用。
4. Skill、组件卡和 Recipe 同步写入上述规则，并保留 ECHO 电平和实体读数为待真机验证。
