# ChatMaker V1.0 当前验收状态

日期：2026-08-17

本文件记录当前源码达到的状态。它不是实体硬件验收报告。

## 已完成的软件能力

- 通用安装器：`auto / doctor / restore / uninstall` 已接入四个 Skill 和共享 MCP；本轮核心集合包含安装器定向测试。
- ChatMaker Knowledge：Nano、Uno、ESP32 DevKit V1、星核板 v4.2.2 的索引、章节与机械资料可读取。
- Nano/Uno：Mind+ 环境发现、真实编译、安全自动烧录入口、串口观察状态和 OLED 仪表盘案例已接入；代表案例已真实编译。
- 星核板：Mind+ 1.8 当前 mPython 兼容目标已真实编译 Blink/串口心跳；Mind+ 2.0 目标保持历史状态。
- ChatWeb：独立课堂页面、ESP32 HTTP 页面和按需 Web Serial 控制台可用；模拟与真实连接分开显示。
- Chat2D：白底底板编辑、板卡和自定义模块拖拽、LaserMaker 四色工艺层、长宽高/材料厚度/榫槽参数、六面指接直角盒、三维组装预览和 DXF/SVG 导出已实现。
- Chat3D：打印外壳、壁/底/盖/安装参数、拖拽旋转、滚轮缩放、平移和 OpenSCAD/STL 导出已实现。

## 本轮轻量验证

- 核心集合：87 tests passed。
- Windows 能力探测与通用安装器补充集合：23 tests passed；可同时发现 `E:\Mind+` 与 `E:\Mind+2`。
- Chat2D 与 Chat3D 生成页：JavaScript 语法检查通过。
- 星核板示例：Mind+ 1.x 真实编译通过，程序 205716 / 1310720 bytes，动态内存 15260 / 294912 bytes。
- Nano/Uno OLED：此前本阶段已分别使用对应 Mind+ FQBN 真实编译通过。
- 本机全局刷新：`chatmaker-install auto` 成功，Codex 与 WorkBuddy 两个宿主均健康，四个已安装 Skill 与仓库源码逐字节一致。

## 仍需用户或同事实测

- Nano、Uno、星核板的实际烧录、重启、串口标记和传感器/显示屏/执行器效果。
- Web Serial 或 ESP32 HTTP 页面与真实设备的一次完整交换。
- Chat2D 盒子的切缝补偿、榫槽试切、螺丝和接口净空、六面装配。
- Chat3D 的切片、孔位小样、上盖配合和完整打印试装。

因此当前可以作为 GitHub `main` 上的 V1.0 快速体验版本继续测试，但在上述实体门槛完成前，不创建“硬件全部验证”的正式 V1.0 Release 标签。
