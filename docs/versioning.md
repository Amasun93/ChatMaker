# ChatMaker 简单版本规则

ChatMaker 只维护一套当前版本，权威位置是 `pyproject.toml` 的 `project.version`。

普通用户看到的格式是：

```text
主版本.功能版本.修正版本-beta.体验轮次
例如：0.2.0-beta.1
```

- `0`：还在正式 1.0 之前。
- `2`：第二轮较大的功能阶段。
- `0`：这一阶段还没有单独的修正版。
- `beta.1`：第一轮 Beta 体验。

不是每次小提交都升级版本。只有面向用户形成一批可说明的变化时，才更新版本。

每次阶段更新必须同时完成四件事：

1. 在 `pyproject.toml` 修改版本。
2. 在 `WHATS_NEW.md` 最上方新增“日期 + 版本”记录，用大白话写已经发布的变化；保留旧记录，不写后续计划。
3. 更新 README 与路线图里的当前状态。
4. 运行 `python scripts/check_version_consistency.py`。

Python 打包规范会把 `0.2.0-beta.1` 写成 `0.2.0b1`。两种写法代表同一个版本；构建脚本会自动转换，不要再手工维护第二个默认版本。
