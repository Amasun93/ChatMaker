# ChatMaker 一分钟演示脚本

## 0–10 秒：说出想法

```text
我有一块经典 Nano、一个光敏模块和一颗 LED。
我想让天黑以后灯自动亮起来。
```

说明：用户不用先知道库名、编译器或 Bootloader。

## 10–25 秒：看懂接线

展示 ChatDuino 的简单 `text` 接线块和完整程序。强调系统会先确认模块针脚丝印和供电，不根据淘宝标题猜型号。

## 25–40 秒：真实编译

运行 Nano 编译。指出当前电脑复用 Mind+ 2.x，编译成功与烧录成功是两件事；没有插开发板时系统会停在等待硬件。

## 40–55 秒：生成课堂网页

打开 `examples/chatweb/classroom-pulse.html`，点击一次主按钮，让计数从 0 变成 1。切换到手机宽度，展示同一个 HTML 文件仍可使用。

## 55–60 秒：收束

```text
ChatMaker 负责把创意变成可检查的作品。
老师负责选择喜欢的方向，并确认真实世界里是否达到效果。
```

不要在没有实物证据时演示或宣称 Nano 已经烧录、灯已经闪烁或传感器已经返回真实数据。
