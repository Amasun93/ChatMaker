# Chat2D 参数化盒子与直接拖放设计

## 目标

Chat2D 不再把“锯齿矩形”和模块表单拼成一个编辑器，而是先由独立参数模型生成可加工的六面盒子，再把同一模型交给画布、SVG 和 DXF。用户的主操作只有一个：从右侧可视化图库把元件直接拖到任意板面。

## 参数化盒子核心

- 新建独立盒子模型，输入外部/内部长宽高、材料厚度、长宽高三组卡榫尺寸、装配补偿、顶盖和底盖状态。
- 每条边由“端部余量 + 凸榫/间隔序列 + 端部余量”组成；余量左右对称。
- 配对边使用互补的凸榫和凹槽。正装配补偿会让凸榫略宽、凹槽略窄，用同批材料试切后再决定数值。
- 每块板的闭合轮廓只能包含水平或垂直线；四个角必须回到真实板角，不允许用斜线连接相邻边。
- Python 参数模型是静态 SVG/DXF 的权威来源；浏览器使用同一参数契约的实时实现，并用代表性几何签名对齐。
- 不直接复制 LaserMaker 专有实现，也不复制 GPL 工程代码；公开工具只用于理解参数职责。

## 直接拖放交互

- 页面改成中央工作区 + 右侧控制区，移除左侧“元件放置面”和“已放置模块”。
- 图库卡片可直接拖动。拖入某块板时，该板自动成为模块所在面，不再要求用户二次选择。
- 已放置模块可继续跨板拖动；拖动幽灵跟随指针，并根据所在板自动切换板面。
- 模块完整落在目标板内时显示绿色；部分越界时显示红色。
- 越界松手时吸附到目标板最近的合法位置；模块整体放不下时回到拖动前的位置。
- 点击模块后右侧只保留名称、旋转和删除等必要操作，不再显示“所在板件”。

## 来源约束的可视化图库

- 图库缩略图使用 ChatMaker 自有机械资料生成红线矢量图：外形、可信安装孔和已有功能开口共同构成模板。
- 模块拖入画布后显示相同图形，不再只显示一个粉色矩形和型号。
- Arduino/板卡的可信安装孔自动随模板移动并导出。
- 星核模块孔中心虽然已知，但孔径标为 `requires_measurement`，因此只显示待测中心标记，不生成切孔。
- 已有可信功能开口（OLED 窗口、DHT11 通风窗、超声波双圆孔、MP3 扬声器孔）可显示为模板图形；按钮帽、电位器轴等未知尺寸仍标记待测，不猜开口。
- 移除安装孔逐项编辑器；自定义模块仍要求真实宽深和孔/开口测量。

## 文字、导出与证据边界

- “显示板件说明文字”开关即时控制中央画布、SVG 和 DXF：勾选就显示，不勾选就同时去掉。
- SVG、DXF 和画布共享盒子参数、模块位置、模板图形与说明文字状态。
- 保留三维近似预览，但不将它当作装配或实体配合证明。
- `model_generated`、`file_opened`、`physical_fit` 继续分离；本轮仍不改 Chat3D、安装器或发布系统。

## 验收标准

1. 六面所有闭合轮廓均为正交线段，四角没有斜线尖角。
2. 长宽高卡榫、厚度和装配补偿会改变对应配对边，且凸榫/凹槽互补。
3. 从可视化图库直接拖到六个板面，无需选择“所在板件”。
4. 跨板拖动自动换面，越界变红，松手后吸附或退回。
5. 左侧已放置列表、板面选择器和安装孔编辑器消失。
6. 模板图形包含来源允许的外形、孔或功能开口，未知尺寸不生成切孔。
7. 文字开关即时同步中央画布、SVG 和 DXF。
8. 聚焦测试与一条真实浏览器路径通过；实体配合仍为未验证。
