# Chat2D 小白模块筛选与展示设计

## 本版目标

模块图库先按用户能理解的系列筛选，而不是把板卡、模块和内部型号混在一张长列表中。当前下拉项为“全部模块、开源硬件、星核板、传感器”。一个模块可以同时属于多个筛选项，例如 DHT11 同时属于星核板和传感器。

卡片、缩略图和放置后的名称使用面向小白的展示名，例如“星核板”“串口 MP3 模块”“DHT11 温湿度传感器”。`IDMC-0001`、`IDMS-0008` 等真实 ID 继续保留在项目数据和机械资料索引中，但不作为界面语言。尺寸、孔位和验证状态仍来自原始 profile，不因展示名变化而改写。

## 数据与交互

- 每条图库记录增加可重叠的 `series` 标签。
- 选择系列后，只筛选图库卡片，不改变已经放到板件上的模块。
- 搜索匹配展示名，不要求小白知道内部编号。
- 自定义实测模板继续进入“全部模块”，不会被误归入已有产品系列。
- 行空板目前缺少 Chat2D 所需的受控外形和孔位资料，因此本版不创建猜测尺寸的卡片；机械资料补齐后再接入同一结构。

## 后续平台方向

如果 ChatMaker 后续成为网页或在线平台，可在同一模块目录上增加用户、班级或授权范围的可见性规则。当前 Skill 版本不实现账号、权限、多租户或后台配置，只确保真实 ID、展示名、系列标签彼此分离，为后续能力保留接口。

## 验收

- 真实浏览器能切换三个系列并得到正确卡片集合。
- 卡片和缩略图不显示 Starcore 内部型号编号。
- 拖放、SVG/DXF 导出和机械真源不受展示层改动影响。
- 页面无控制台错误或警告。
