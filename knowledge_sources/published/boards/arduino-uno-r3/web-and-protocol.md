# Define communication before building the page

Canonical board `arduino-uno-r3` does not have native Wi-Fi and therefore needs a host or an extra communication route for a web experience. Agree on the message contract first. Then load canonical records for the communication component and chosen recipe. Browser rendering, message exchange, board runtime, and physical effect remain independent observations and must be reported as separate evidence.
