# Follow current toolchain state

Load toolchain choices and their current statuses from canonical `arduino-uno-r3`; this page does not freeze commands or versions. Confirm board identity and the wired upload target before acting. Record environment discovery, source generation, compilation, firmware upload, serial behavior, and physical effect separately. Never translate successful compilation into an upload claim, or an upload result into observed hardware behavior.
