# Combine board, component, and recipe data

Start with canonical board `arduino-uno-r3`. Load every requested component through its canonical ID and use a canonical recipe when available. Component records own interface and safety facts, while recipes describe the intended connection. Give the learner one reversible action at a time and the observation expected next. Stop when the actual module cannot be matched confidently to its record.
