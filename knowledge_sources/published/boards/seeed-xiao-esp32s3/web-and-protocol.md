# Seeed Studio XIAO ESP32S3｜串口、网页和通信

USB 串口 115200 先看到周期打印。做网页时再接入 2.4 GHz Wi-Fi，按 Seeed 指引在断电状态连接配套天线。网页通信与传感器实测分别确认。
