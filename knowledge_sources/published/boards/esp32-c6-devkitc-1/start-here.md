# ESP32-C6-DevKitC-1 从这里开始

在板子上找 `ESP32-C6-DevKitC-1`，再用模组印字、包装或采购记录确认 8 MB。官方订购表列有 `ESP32-C6-DevKitC-1-N8`。ChatMaker 对应板卡是 `esp32-c6-devkitc-1`。

第一次先把 USB 数据线插在官方图标出的 USB 转串口，用串口小程序看板子有没有运行。接着试板载彩灯。识别、接线和网络分别有小节，碰到端口问题可先看「课堂常见问题和排错」。

[乐鑫 v1.2 板卡介绍和订购表](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c6/esp32-c6-devkitc-1/user_guide.html)
