# 网页项目先统一单位和状态

3.0 可使用 Wi-Fi、Bluetooth LE 或串口与网页交互。协议中要明确光线使用 lux、声音读数范围、运动数据轴向、按钮事件和断线状态。网页仿真只用于验证交互，不替代板卡通信证据。

依次验证板端运行、实际消息、网页接收、控制回传和实体效果，不能从其中一个阶段推断全部完成。
