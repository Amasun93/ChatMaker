# Arduino UNO R4 WiFi｜从这里开始

先用 USB-C 数据线让板上的点阵闪出一颗心。它适合从灯光、按钮过渡到联网提醒。选板时用 `arduino-uno-r4-wifi`。

[Arduino 板卡介绍](https://docs.arduino.cc/hardware/uno-r4-wifi/)
