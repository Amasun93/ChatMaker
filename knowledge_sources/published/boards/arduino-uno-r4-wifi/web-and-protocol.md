# Arduino UNO R4 WiFi｜串口、网页和通信

先用 USB 串口 115200 看心跳文字，再单独验证 Wi-Fi 扫描、连网和网页请求。真实网络密码只留在用户本机。点阵亮起和网络请求成功分别记录。
