# 微雪 ESP32-S3-Touch-LCD-2.8

这里对应板上写着 `ESP32-S3-Touch-LCD-2.8` 的微雪触屏板。看背面标记确认版本。V1 是 CST328，V2 是 CST3530。产品名带 2.8B 或 2.8C 时，需要该型号自己的资料。

第一次做作品，可以先用屏幕诊断确认显示，再用触屏计时器检查开始、暂停和重置。两个例程在仓库的 `examples/chatduino/waveshare-s3/`。问板型、接线或原理时，可直接读本 Wiki。第一次编译才需要检查本机是否已经有这块板的工具。

V1 和 V2 都有真实编译记录。烧录、屏幕显示、触摸和断电重启分别验收。[微雪板卡资料](https://docs.waveshare.net/ESP32-S3-Touch-LCD-2.8/)
