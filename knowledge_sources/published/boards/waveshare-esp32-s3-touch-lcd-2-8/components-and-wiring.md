# 先用板上现成的屏幕和触摸

屏幕是 ST7789，触摸驱动按 V1 或 V2 选。屏幕诊断和计时器直接使用板上的器件，接电脑的 USB 数据线即可做这两项测试。

加外部模块时，先找到模块型号和实际丝印，再按板型给出供电、地线和信号的对应关系。已接好的线先判断能否保留。板卡的 CAD 外形和安装孔资料仍需单独核对，紧配外壳和接口开口需要实物试装。[微雪资料和机械图入口](https://docs.waveshare.net/ESP32-S3-Touch-LCD-2.8/Resources-And-Documents/)
