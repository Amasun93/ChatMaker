# Choose an example through its recipe

Use canonical board `arduino-nano-classic` and select a checked-in recipe such as `nano-blink-built-in` or another `nano-` recipe that matches the learner's parts and goal. Load that recipe before choosing libraries or source. Preserve every verification status found there. An example that compiled previously is guidance, not evidence that today's board was uploaded or observed.
