# Load shared component records

Begin with canonical board `arduino-nano-classic`, then load each requested component by its canonical ID and use a matching canonical recipe when one exists. The shared component record owns interface and safety facts; the recipe owns the intended relationship between parts. Describe one reversible connection at a time, state what the learner should observe, and stop if a module variant cannot be identified.
