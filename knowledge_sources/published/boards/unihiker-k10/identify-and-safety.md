# DFRobot UNIHIKER K10 行空板｜识别板型和用电安全

K10 是用 USB 写入程序的微控制器。看清 K10 或 DFR0992，M10 的 Python 同步走另一条路线。先用 USB-C 数据线供电。Arduino 程序会替换板上原应用，先留好想继续用的程序或出厂恢复资料。
