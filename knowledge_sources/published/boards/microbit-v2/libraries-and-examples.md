# 从心形状态案例开始

代表案例位于 `examples/chatduino/microbit-v2/heart-status/main.py`，使用 MicroPython 显示心形并输出串口状态。它已经通过源码检查和 HEX 打包，且从 HEX 反向读取出的 `main.py` 与原文件一致。

当前没有 micro:bit 实板，因此不能把这个结果写成 LED 已显示、按键已响应或串口已观察。拿到 V2 实板后，应从这个小案例补齐真实下载和实体证据。
