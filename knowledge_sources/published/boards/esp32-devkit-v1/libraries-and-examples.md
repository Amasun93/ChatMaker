# Select only checked-in canonical recipes

Use canonical board `esp32-devkit-v1` and choose between the existing recipes `esp32-external-led-blink` and `esp32-ap-led-sensor` according to the learner's intended effect. Load the complete recipe before selecting libraries or source. Preserve every verification gate exactly as recorded. Example availability and source review never prove compilation, upload, network exchange, or physical behavior on the current board.
