# ESP32-S3-DevKitC-1-N8R8 从这里开始

这里对应乐鑫 `ESP32-S3-DevKitC-1-N8R8`，ChatMaker 中选 `esp32-s3-devkitc-1-n8r8`。把载板正面、背面和方形金属罩上的模组型号一起拍下来。模组后缀影响编译配置，载板版本影响板载彩灯如何接。

第一次只需要 USB 数据线。先从标为 USB-to-UART 的插口看串口小程序，再按板卡版本试彩灯。做图像缓存等需要额外内存的作品时，再检查 PSRAM 是否正常工作。
