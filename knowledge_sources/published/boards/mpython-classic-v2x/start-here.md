# 先确认是哪一代掌控板

经典掌控板是 ESP32 加 128×64 单色 OLED 的 V2.x 产品，不是彩屏的掌控板 3.0，也不是使用掌控板软件目标的星核板。接板后先调用自动识别；仍不确定时查看正面或背面的“掌控板”和版本丝印，看不懂就拍摄正反面照片交给 AI。

确认板型后再选择 Arduino 或 MicroPython。V2.0、V2.1、V2.2/V2.3 的运动与磁场传感器不完全相同，涉及体感或指南针时必须继续确认修订版本。
