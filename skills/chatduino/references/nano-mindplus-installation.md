# Mind+ 检测与安装路由

## 优先级

1. 已安装 Mind+ 1.x：复用并检查 Nano 工具链。
2. 已安装 Mind+ 2.x：复用并检查 Nano 工具链，不要求降级。
3. 两者都有：使用通过 Nano 编译自检的现有后端；不要重复安装。
4. 两者都没有：识别操作系统、发行版、系统版本和 CPU 架构，优先走官方 1.x。

## 官方 1.x 路线（2026-08-14 核实）

官方入口：`https://mindplus.cc/download.html`

| 系统/架构 | 官方 1.x 路线 |
|---|---|
| Windows x64，Win7/8/10/11 | V1.8.1 RC3.0 安装版 |
| macOS Intel，10.11+ | V1.7.3 RC2.0 |
| Linux x86-64 / ARM64 | V1.7.3，进入官方 Linux 页面选架构 |
| 银河麒麟 V10 | 官方 V1.7.4 专用包 |
| 统信 UOS | 官方 V1.7.4 专用包 |
| 龙芯 MIPS | 官方 V1.7.1 路线 |
| 龙芯 LoongArch | 官方对应 1.7.3 起的路线 |

官网没有明确确认 Windows ARM 或 Apple Silicon 的原生 1.x 包；这两类设备不能自动下载一个看似相近的 x64 包。报告兼容性待确认，必要时再评估已有 2.x 或系统兼容层，并重新验证 Nano 工具链。

## 完成门槛

下载完成、安装完成、软件能启动、Nano 编译链就绪、驱动可见、Blink 编译成功、实体 Nano 烧录成功是不同状态。每一步分别报告。安装器需要系统管理员确认时，让老师在可见安装界面中操作；不要绕过权限或安全提示。
