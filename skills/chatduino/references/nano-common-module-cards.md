# 淘宝常见杜邦线模块卡

模块卡描述的是可由针脚丝印确认的常见版本，不以商品标题代替型号。针脚顺序必须看实物丝印，不能按图片左右位置猜。

## 普通 LED

- 识别：两脚 LED，长脚通常为正极；扁边/短脚通常为负极。
- 接线：Nano 数字输出 → 220-1000 Ω 限流电阻 → LED 正极；LED 负极 → GND。
- 不允许省略限流电阻。板载 LED 可直接使用 D13，仅适合最小测试。

## RGB LED

- 先确认共阴还是共阳、四脚顺序和是否为带电阻模块。
- 共阴公共脚接 GND；共阳公共脚接 5V，程序输出逻辑相反。
- 裸 LED 的 R/G/B 三路分别串限流电阻。需要调色时三路使用 PWM 引脚。

## 光敏传感器

- 裸光敏电阻需要与固定电阻组成分压，分压点接 A0。
- 三针/四针模块常见丝印为 `VCC/GND/AO/DO`：AO 是连续模拟量，DO 是电位器阈值后的数字量。
- 老师只说“光敏模块”时，先看是否有 AO、DO 和板载电位器，再决定代码。

## 按钮与微动开关

- 两脚按钮可采用 `INPUT_PULLUP`：一端接数字引脚，一端接 GND；按下为 LOW。
- 四脚轻触按钮内部同侧通常已经相连，必须确认跨边接线。
- COM/NO/NC 微动开关按需求选 COM+NO 或 COM+NC。

## 蜂鸣器

- 有源蜂鸣器给高/低电平即可鸣叫；无源蜂鸣器需要 `tone()` 产生频率。
- 模块常见 `VCC/GND/I/O`；裸蜂鸣器和大音量模块可能需要三极管驱动。
- 只说“蜂鸣器”时先确认有源/无源或模块型号。

## HC-SR04 超声波

- 针脚通常为 `VCC/TRIG/ECHO/GND`，VCC 接 5V，GND 接 GND。
- 默认 TRIG=D7、ECHO=D8。经典 5 V Nano 可直接读取 ECHO。
- 代码必须给 `pulseIn` 超时，避免传感器断开后程序永久等待。

## DHT11 温湿度

- 三针模块通常为 `VCC/DATA/GND`；裸四脚 DHT11 需要确认正面朝向和上拉电阻。
- 默认 DATA=D4，读取间隔不少于约 2 秒。
- 使用 Mind+ 对应 DHT 库前，先真实编译确认头文件与 API。

## SG90 舵机

- 常见线色：棕/黑=GND，红=5V，橙/黄=信号；仍以产品说明为准。
- 信号默认 D9。舵机不能从 Nano GPIO 取电；多个舵机或负载较大时使用独立 5V 电源并共地。
- 上电先进入安全角度，机械结构未确认时避免快速扫满 0-180°。

## 0.96 英寸 I²C OLED（SSD1306 128×64）

- 只在四针丝印明确为 `GND/VCC/SCL/SDA` 且控制器确认是 SSD1306 时使用本卡。
- Nano：SDA→A4，SCL→A5；常见地址 0x3C，也可能是 0x3D。
- SPI 七针屏、SH1106 或其他分辨率不能套用本卡。屏幕不亮时先跑 I²C 扫描，不先改库名碰运气。

## 继电器模块

- 低压控制端常见 `VCC/GND/IN`，先确认高/低电平触发。
- `COM/NO/NC` 属于负载侧。教师培训默认只演示安全低压负载；不指导学员带电操作市电。
- 上电默认关闭负载，并确认模块输入电流是否需要驱动级。
