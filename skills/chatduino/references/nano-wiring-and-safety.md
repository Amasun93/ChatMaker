# 接线与供电安全

1. 改线前拔掉 USB 和所有外部电源。
2. 按实物针脚丝印逐线连接，不按杜邦线颜色猜功能。
3. 任何外部电源控制的模块都必须与 Nano 共地，除非使用明确隔离接口。
4. Nano GPIO 只负责逻辑信号。电机、水泵、灯带、多个舵机和大功率继电器使用驱动器和独立电源。
5. 普通 LED 每一路串联限流电阻；感性负载使用合适的续流保护。
6. 检查模块工作电压和输出电平。经典 Nano 是 5 V 逻辑，但某些显示屏、传感器芯片只支持 3.3 V。
7. USB 与外部 5 V 同时供电前确认供电路径，避免两个电源互相回灌。
8. 烧录前断开 D0/D1 上的外设，关闭占用串口的监视器和其他软件。
9. 市电、加热器、大电流电池和机械执行器不作为普通教师上手实验；必须由具备资质的人员另行评估。

排错顺序：断电目检 → 模块型号/针脚丝印 → 电源电压 → 共地 → 线序 → 引脚占用 → 串口/地址 → 库与代码 → 阈值校准。
