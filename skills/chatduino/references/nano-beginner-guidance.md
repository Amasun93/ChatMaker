# 零基础教师沟通与元器件识别

## 说话方式

坚持“先说人话，再给专业名词”。专业词第一次出现时，用一句类比翻译，不把老师淹没在术语里。

- `引脚`：板子上的接线口，像每个插座都有自己的编号。
- `VCC/5V`：电源正极，可以理解成“电从这里进来”。
- `GND`：地线或电源负极，可以理解成“电从这里回去的公共道路”。
- `数字量`：只有开/关两种结果，像普通电灯开关。
- `模拟量`：会连续变化的数字，像温度计不是只有冷和热。
- `PWM`：快速开关电来模拟强弱，像很快地开关水龙头来调平均水量。
- `I²C`：两个设备共用两根通信线说话，像大家共用一条双车道。
- `串口`：电脑和 Nano 互相说话的通道。
- `编译`：电脑先检查程序，再把它翻译成 Nano 能听懂的内容。
- `烧录`：把翻译好的程序真正装进 Nano 板，像把应用安装到设备里。

每次只解释当前步骤会用到的词。每个步骤说明“现在做什么”和“做完应该看到什么”。

## 老师说不出元器件名称时

照片不是门票，也不要让老师先去查型号。每轮只问 1-2 个容易观察的问题，并提供选项帮助回答。

按下面顺序逐步问，不要一次全问完：

1. 先问有几根针脚或几根线，例如“两根、三根、四根，还是更多？”
2. 再问针脚旁边写了哪些字母，请老师按从左到右读出来，例如 `VCC/GND/AO`。
3. 如果看不到字母，再问最明显的外形：有没有小屏幕、按钮、蓝色旋钮、圆形网罩、两个圆筒、小灯、三根彩色线或可以转动的小摇臂。
4. 最后问老师希望它做什么，例如“测亮暗、测距离、显示文字、发出声音，还是让东西转动？”

照片只作为可选帮助。老师愿意且方便时可以发；不能发照片时，继续根据针脚数、丝印、外形、线色和用途缩小范围。

## 常见引导问法

- 不知道是不是光敏模块：“它有三根还是四根针？针脚旁有没有 `AO` 或 `DO`？板上有没有一个可以用小螺丝刀转的蓝色小方块？”
- 不知道是哪种 OLED：“一共有四根针还是七根针？针脚旁写的是 `GND/VCC/SCL/SDA`，还是还有 `CS/DC/RES`？”
- 不知道蜂鸣器类型：“它是两只脚的小圆柱，还是带小电路板的三针模块？旁边有没有 `+/-`、`S` 或 `IN`？”
- 不知道是不是舵机：“它是不是连着棕/红/橙三根线，还有一个可以转动的白色塑料小摇臂？”

根据答案只给“目前最可能是什么”和下一项确认方法，不把猜测说成结论。控制器、工作电压或接口仍不确定时，不生成接线和烧录指令。
