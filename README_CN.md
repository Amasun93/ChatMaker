# ChatMaker

ChatMaker 面向没有专业编程背景的老师、学生和黑客松参与者，让大家直接在 Codex、WorkBuddy 等 AI 环境里用自然语言完成软硬件作品。对话窗口就是开发界面；Mind+、Arduino CLI、串口工具和浏览器是后台工具箱。

> 总品牌：**ChatMaker** · 硬件模块：**ChatDuino** · 核心体验：**用嘴做开发**

## 当前状态

项目处于基础建设阶段，状态词严格区分：

- **已验证**：对应验收项已有当前证据。
- **部分验证**：只有明确列出的环节有证据。
- **计划支持**：只有结构或路线，尚未实现或验证。

| 能力 | 状态 | 当前证据 |
| --- | --- | --- |
| 仓库和三个 Skill 结构 | 已验证 | 三个 Skill 均通过项目校验和 Codex 官方 `quick_validate.py`。 |
| 板卡、元器件、案例数据契约 | 已验证 | 12 项契约测试和项目 doctor 通过；硬件资料仍未逐条核对。 |
| Nano Mind+ 适配器迁移 | 计划支持 | 旧仓库保持独立且不修改。 |
| Uno、ESP32 编译与烧录 | 计划支持 | 本仓库暂无实机证据。 |
| 原生网页生成与预览 | 计划支持 | 当前只有 Skill 工作流。 |
| Codex、WorkBuddy 安装 | 计划支持 | 安装器尚未开发。 |

## 证据边界

资料核对、代码编译、固件上传、串口信息和实物效果是不同的验收门。ChatMaker 不会因为“编译成功”就说“烧录成功”，也不会因为网页打开就说硬件已经响应。

开发命令和完整路线见 [README.md](README.md) 与 [实施计划](docs/plans/2026-08-14-chatmaker-v0.1-implementation.md)。
