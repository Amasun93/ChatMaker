# 星核智能感应盒参数化示例

这个示例证明 Chat3D 可以不经过 Chat2D，直接从一份请求生成完整参数化盒体。盒内安装星核板，顶盖安装 OLED、超声波和温湿度模块，并生成经过资料约束的固定孔、功能开口、中文项目名称和一个可调整的侧边线束出口。

可直接调整 `request.json` 中的盒体尺寸、模块 `x` / `y` / `rotation`、文字、安装孔策略和 `side_openings`。侧边出口的 `position` 在前后板表示 X 坐标，在左右板表示 Y 坐标；`z` 是相对内腔底面的中心高度。

`preview-lab.html` 用于课堂参数预览，完整安装柱、开口和线束出口以同目录 OpenSCAD 源码及其 OpenSCAD 渲染结果为准。生成文件不代表实体装配已经验证；第一次打印前仍应先打印孔位或开口小样。
